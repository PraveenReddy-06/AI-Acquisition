Phase 5 — Frameworks

Only now we'll introduce:
LangChain
You'll recognize everything underneath it:
Your manual code             LangChain

PDF extraction       →       Document Loader
Chunking             →       Text Splitter
Embedding            →       Embedding Model
ChromaDB             →       Vector Store
Retrieval            →       Retriever
Prompt               →       Prompt Template
Ollama               →       LLM

So instead of blindly learning:
some_langchain_function(...)


you'll know exactly what that function is doing internally.
LlamaIndex
We'll learn:
- what it solves
- document indexing
- retrieval
- query engines
- when to choose LlamaIndex vs LangChain
